# 5.0.1

## Fixes

- **Translate formatters are type checked.** Calls to the built-in `format("number" | "datetime" | "list", ...)` formatters with the wrong value or option types now fail to compile instead of falling back to an unchecked overload. `datetime` accepts timestamps and date strings, as it already did at runtime, and `number` keeps bigint precision. See [Built-in formatters](../../src/translate/README.md#built-in-formatters).
- **A view that throws while rendering no longer affects later signals.** Signals created afterwards anywhere in the app took the failed view's name and its root's debug setting.
