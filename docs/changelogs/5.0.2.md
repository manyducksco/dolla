# 5.0.2

## Changes

- **`addStore` can leave out props when none are required.** A store typed `(_: {}, c)` or `({ label }: { label?: string }, c)` no longer needs an explicit `{}`. Like views, the store then receives an empty object, so give optional props defaults by destructuring (`{ label = "none" }`) rather than with a default parameter. See [Stores](../components.md#stores).
