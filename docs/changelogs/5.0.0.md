# 5.0.0

Dolla 5.0 has a smaller main entry, a structured error pipeline, simpler effects and a long list of fixes, some of which change behavior. Upgrading from 4.9 needs code changes: the [migration guide](../migrating-to-5.md) covers each one, and most apps only need its [checklist](../migrating-to-5.md#checklist).

## Breaking changes

- **Smaller main entry.** Low-level APIs (`createEffect`, `subscribe`, `createMarkup`, `render`, the node classes, `createContext` and others) moved to `@manyducks.co/dolla/internals`, and `styled` moved to `@manyducks.co/dolla/styled`. See [Moved APIs](../migrating-to-5.md#moved-apis).
- **Renamed APIs.** `forEach` is now `repeat`, `unwrap` is `get`, `showUnless` is `hideIf`, `hideUnless` is `showIf`, and the `:name` attribute shorthand is `attr:name`.
- **Removed APIs.** `keepAlive`, `onShow`, `onHide`, `isVisible`, `createView`, `createStore`, `ReactiveProps`, `Env`, `css.named()`, `template.named()`, `template.preinsert()` and `http.trace()` are gone. Hidden branches always unmount. See [Removed APIs](../migrating-to-5.md#removed-apis).
- **Effects don't take deps.** `onEffect` and `createEffect` track what they read; use `peek` for values that shouldn't trigger a re-run. `onEffect` returns a function that stops the effect early. See [Effects](../migrating-to-5.md#effects).
- **Errors are reported, not thrown.** Errors in effects, cleanups, scheduled DOM updates and lifecycle listeners are wrapped in a `SignalError` and sent to `createRoot(..., { onError })`, or to `reportError` without one. See [Errors](../errors.md).
- **Router params use `:name`.** `{name}`, `{#name}` and `{name?}` params and `router.block()` are gone. See [Router](../migrating-to-5.md#router).
- **Stores are identified by their function**, not by name, so two stores with the same name no longer collide.
- **Generated CSS class names changed.** Don't select them in CSS or tests. Classes passed to a `styled` component now override its base styles.
- **`setLocale` rejects a locale with no translations** instead of loading the first one. Pass no locale to pick one from the browser's languages.

## Features

- `createRoot` takes `{ debug, onError }`, and debug mode is per root.
- New `keyframes` helper for animations with generated names. See [Animations](../css.md#animations).
- Reactive css values are set as custom properties on the element instead of creating a class per value, and Dolla warns when one `css` call site creates many classes.
- Loaded translations are cached and dropped after five minutes unused, and an unknown formatter logs a warning.
- The Vite plugin keeps stores and views stable across more export forms during hot reload, and only runs on the dev server.
- JSX types now resolve in consumer projects, and `vite` is an optional peer dependency.

## Fixes

- **Rendering:** sibling order after container nodes, elements leaking reactive props or duplicating children when remounted, reactive style values of `0`, `null` clearing properties, `repeat` moving fewer DOM nodes and handling duplicate keys, and transitions after a quick show/hide toggle.
- **Effects and signals:** cleanups run untracked, child effects are disposed before a re-run, writable computed setters no longer break downstream values, composed values that throw recover, and runaway update loops are stopped.
- **Router:** query strings and fragments are kept, malformed percent-encoding doesn't crash, redirect loops throw instead of hanging, stale navigations are ignored, hash mode keeps the base path, and nested routes merge `meta`.
- **HTTP:** repeated query keys are kept, JSON bodies are serialized when you set the content type, empty and error responses don't fail to parse, and relative paths starting with "http" stay relative.
- **Translate:** nested plural and context variants resolve, missing variants fall back to the base key, getter options and counts are read, and overlapping `setLocale` calls let the last one win.
- **Virtual lists:** heights are invalidated and measured correctly as the list changes, and observers, listeners and timers are released on unmount.
- **CSS:** class name collisions, at-rule extraction with strings and conditions, and template bindings released when a template is removed.
- **HMR:** properties attached to exported functions survive hot reload.
